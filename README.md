## My Data Analytics Workflow

My analytical projects generally follow six stages:

1. **Problem Definition** — Identify analytical objectives and relevant business questions.
2. **Data Preparation** — Inspect, clean, validate, and transform source data.
3. **Data Modelling** — Structure datasets and establish appropriate relationships.
4. **KPI Development** — Define performance indicators and analytical measures.
5. **Dashboard Development** — Create interactive reports and visualizations.
6. **Insight Communication** — Interpret findings and communicate decision-support information.
